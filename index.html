RSA Investigator

Choose key values, predict what will happen, then examine the results. Use this application to collect evidence for your RSA investigation.

This is a textbook RSA teaching tool using small numbers. Successful message recovery does not establish practical security. Calculations run locally in your browser.

Configure an experiment

Use distinct primes. The application calculates n = p × q and φ(n) = (p − 1) × (q − 1). The modulus n must not exceed 10,000.

Enter positive whole numbers for e and d. The application allows exponent choices that may fail to recover messages, so you can investigate their behaviour.

Separate whole numbers with commas, spaces or new lines. Each must be between 0 and n − 1. Enter each message once, up to 1,000 messages per selected test. Update this list when changing the modulus.
